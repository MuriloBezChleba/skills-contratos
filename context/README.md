# Contexto compartilhado do projeto

Leia [projeto](project.md), [glossário](glossary.md), [decisões](decisions/README.md) e o contexto da feature em execução.

Contratos compartilhados: [modelos](../contracts/models/README.md) e [módulos](../contracts/modules/README.md).

Cada feature possui contract.md, context.md, evidence.md e skills.lock.json em context/features/F001-nome/. Estes documentos acompanham código e contratos no mesmo PR. GitHub recebe o contexto após commit e push autorizados.
