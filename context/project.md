# Projeto

Adaptação local do repositório mattpocock/skills para contratos de contexto, modelos e módulos.

## Limites

Preservar skills existentes, licença e histórico upstream. Não publicar nem instalar globalmente implicitamente.

## Comandos de verificação

- node --test contract-tools/tests/integration.test.mjs
- node scripts/sync-plugin-version.mjs --check
- claude plugin validate . --strict

## Branches

Uma branch feature/F001-nome por feature. Código e documentação acompanham o mesmo PR.
